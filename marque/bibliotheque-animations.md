# Bibliothèque d'animations — style TikTok viral

Effets d'habillage utilisés par `directeur-artistique` et `monteur-video`. Couleurs et polices : `marque/charte-graphique.md`. Le `stratege-contenu` ajoute ici les effets repérés dans les vidéos qui marchent.

Chaque effet a un code (ex. `SUB-1`) à utiliser dans les feuilles d'habillage.

## Règle d'or
Un effet sert à **garder l'attention ou à faire lire l'avantage**. Si un effet ne fait ni l'un ni l'autre, on l'enlève. Au maximum un effet « fort » toutes les 3 secondes.

## Sous-titres animés
| Code | Effet | Réglages | Quand |
|---|---|---|---|
| `SUB-1` | Mot par mot (karaoké) : le mot prononcé passe en orange | Poppins SemiBold 60 px, blanc, contour noir 6 px, mot actif `#E89838` et agrandi à 110 % | Par défaut sur toute vidéo parlée |
| `SUB-2` | Apparition « pop » groupe de 2-3 mots | Échelle 80 % → 105 % → 100 % en 0,15 s | Voix off rapide, humour |
| `SUB-3` | Mot-clé géant | Le mot clé seul en Montserrat ExtraBold 140 px, 0,6 s, puis retour aux sous-titres | « MOITIÉ PRIX », « GRATUIT », « 12,50 € » |
| `SUB-4` | Emoji associé | Un emoji à côté du mot-clé, 0,8 s, rebond | Au plus 1 toutes les 5 s |

Position : centre de l'écran, légèrement sous les yeux du sujet, jamais dans les 480 px du bas.

## Recettes prêtes à l'emploi
- **Explicatif « moitié prix » (20-30 s)** : `TIT-1` → `TIT-2` → `SUB-1` tout du long → `TIT-4` → `SUB-3` « 12,50 € » + `MOV-1` → `GFX-5`.
- **Avant/après (15-20 s)** : `TIT-1` « 2 HEURES » → `MOV-4` accéléré → `TRA-1` volet → `GFX-3` → `GFX-5`.
- **Coulisses / humour (15-25 s)** : `MOV-3` jump cuts → `SUB-2` → `SUB-4` → `MOV-5` sur la chute → `GFX-5`.
- **Réponse à un commentaire** : `GFX-4` → `SUB-1` → `GFX-2` sur la preuve → `GFX-5`.
- **Tutoriel en étapes** : `TIT-1` → `TIT-6` par étape → `GFX-3` → `GFX-1` → `GFX-5`.

## Comment les réaliser
- **CoDesign** (serveur MCP `codesign`) : charger `codesign:handbook`, `codesign:api`, `codesign:animate`, `codesign:judge` ; la référence vidéo et audio est `skill://codesign/handbook/video.md`. Vérifier le rendu avec `preview` à plusieurs instants.
- **CapCut** (finition humaine) : sous-titres automatiques puis style « mot par mot », animations de texte « Pop » / « Typewriter », effets « Zoom » et « Shake », transitions « Wipe » et « Whip ». Skill `social-media-skills:capcut`.
- Les noms d'effets CapCut changent selon les versions : décrire l'effet voulu plutôt que de compter sur un nom exact.
