# Feuille de route

## Étape 1 — Application fonctionnelle (faite)
App mobile complète tournant sur le web, serveur IA, schéma de base de données, tests, documentation.

## Étape 2 — La brancher pour de vrai (dépend du propriétaire)
1. Clé API Anthropic → vraies réponses, puis relecture de conversations types (tristesse, rupture, crise, franchise) pour ajuster les consignes.
2. Hébergement du serveur → lien public, disponible 24h/24.
3. Clé YouTube → vidéos vérifiées.

## Étape 3 — Sur de vrais téléphones
1. Build de développement iOS et Android (EAS), test du mode vocal avec un vrai micro.
2. Corrections d'ergonomie propres à chaque plateforme (clavier, zones sûres, permissions).
3. Rappels : programmation réelle des notifications.

## Étape 4 — Comptes et protection
1. Projet Supabase, déploiement du schéma, synchronisation facultative.
2. Vérification du jeton côté serveur, limites d'usage par compte.
3. Suppression de compte côté serveur, verrouillage de l'app par code ou biométrie.

## Étape 5 — Avant d'ouvrir au public
1. Relecture des consignes de sécurité et des exercices par un·e psychologue.
2. Textes juridiques validés par un·e juriste, analyse d'impact (AIPD).
3. Abonnement (freemium) si les coûts le demandent.
4. Fiches App Store et Google Play, captures, déclaration de confidentialité.

## Plus tard
Voix avancée en option, programmes guidés sur plusieurs jours, autres langues, base de connaissances validée.
